# Spotify Music Analysis – Power BI

## Project Overview

This project uses Power BI to analyze Spotify music data and identify
patterns in track popularity, artists, music duration, and other
track characteristics.

The goal is to turn raw Spotify data into useful insights through
data cleaning, analysis, and interactive visualization.

## Business Questions

- Which artists have the most popular tracks?
- Which tracks have the highest popularity?
- Which artists have the most tracks in the dataset?
- What is the average track duration?
- How does track duration vary across artists?
- Which artists generate the highest total popularity?
- What are the most popular tracks?
- How does popularity differ across music characteristics?
- Are there duplicate tracks in the dataset?
- What trends can be identified from the Spotify data?

## Tools Used

- Power BI
- Power Query
- DAX
- Excel/CSV

## Data Preparation

The dataset was cleaned and transformed using Power Query.

Data preparation included:

- Removing duplicate records
- Checking for missing values
- Correcting data types
- Cleaning text fields
- Creating calculated columns where required
- Preparing the data for visualization

## Key Metrics

- Total Artists
